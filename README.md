# Telemetria GT73

Página web que mostra a telemetria de uma moto elétrica com controladora FarDriver, lendo por Bluetooth
o módulo serial (YuanQuFOC) que fica só escutando a linha controladora → painel.

- Só escuta: nunca escreve no módulo nem na controladora.
- Mostra velocidade, freio, carga, distância, tempo, médias e freadas; exporta a viagem em CSV.
- iPhone: abrir no navegador Bluefy. Android: Chrome.
